# Coruna iOS

[English](README.en.md) | 简体中文

Coruna iOS 是一个实验性项目，目标是将 Coruna 利用程序从原来的 Web 实现迁移为原生 iOS App。

## 项目目标

本仓库用于研究、整理并适配 Coruna 的利用流程，使其能够在 iOS App 环境中运行，而不是依赖原本的 Web 触发方式。

计划工作包括：

- 在原生 iOS App 结构中复现 Coruna 的利用流程。
- 拆分利用逻辑、界面逻辑和设备相关配置。
- 随着移植推进，补充构建、测试和验证流程文档。
