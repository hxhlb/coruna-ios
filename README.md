# Coruna iOS

## 中文说明

Coruna iOS 是一个实验性项目，目标是将 Coruna 利用程序从原来的 Web 实现迁移为原生 iOS App。

### 项目目标

本仓库用于研究、整理并适配 Coruna 的利用流程，使其能够在 iOS App 环境中运行，而不是依赖原本的 Web 触发方式。

计划工作包括：

- 在原生 iOS App 结构中复现 Coruna 的利用流程。
- 拆分利用逻辑、界面逻辑和设备相关配置。
- 随着移植推进，补充构建、测试和验证流程文档。

## English

Coruna iOS is an experimental project that aims to port the Coruna exploit flow from a web-based implementation into a native iOS app.

### Goal

The goal of this repository is to study and adapt the Coruna exploit program so it can run inside an iOS app environment instead of relying on the original web delivery flow.

Planned work includes:

- Reproducing the original Coruna exploit flow in a native iOS app structure.
- Separating exploit logic, UI, and device-specific configuration.
- Documenting the build, test, and validation process as the port evolves.
